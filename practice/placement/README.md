# 両目の配置 ① v166

最初の「顔の中で両目をなぞる」1枚。既存6種類を選択可能。片目を描き足す／目印だけ／見て配置は実習後の次段階。

顔は完成したface/assets/face.pngをそのまま使用。幅・スケール・crop・用紙サイズ・マス内座標は顔教材と共通（片目170 native pxを30mmとする基準比率、耳込み574pxで約101mm）。種類ごとの実際の眼幅は元の形によって異なる。全種類を個別に30mmへ引き伸ばすことはしない。

目は既存eyes/assets/*.pngを再使用。v149 assets.cjsの1040x520正規化をsources.jsのnative sourceサイズとscaleから逆変換。元のKIT_TWIN.partsのグローバル配置から顔のsourceOffset589,111を引くため、工房の顔と目の位置関係をそのまま維持。新しい目の輪郭は描かない。眉を含む。

目頭/目尻は既存描き順profileの上まぶた端近傍からalpha>80の原画画素にsnap。十字はその両点の中点（ひとみの中心ではない）。補助線は左右の中点を結ぶため原画の傾きを維持。赤丸=目頭、青四角=目尻、青緑十字=まん中。間隔括弧、顔の中心軸。ガイド非表示も選べる。

左は見本、右は元の輪郭を固定して目と眉を.24でなぞる。完成済みの輪郭教材・目教材の描画仕様は変更せず、リンクのみ追加。

PNG物理解像度、A4横100%と5cm目盛り、PSD6層は既存共通writer使用。用紙最下、練習最上、目印と目の薄線は別層。ブラウザー描画なし。
