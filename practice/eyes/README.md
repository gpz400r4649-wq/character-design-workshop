# 目の練習ドリル v151

ユーザー写真の意図は、工房の目の素材自体に描き順を適用すること。v150で作った簡略図を廃止し、v149からある6種類の実素材PNGを直接描画する方式へ変更。

- `assets/*.png` は変更なし。元の目、眉、まつ毛、瞳内部の模様を含む線画。
- `stroke-guide.js` は元の画素を4群に分けて色替えする。線の座標・形・alphaは増減しない。補助Bezierは矢印だけで、目を描き直す用途には使わない。
- 順番の例: ①まぶた・まつ毛 ②まゆ毛 ③黒目・ひとみ ④目の光。進行前の線は薄く、現在の線だけ色を強める。
- 順番シートと、なぞる→目印→空欄の練習シート。写真どおり両目が既定。両目はA4横、左右別の片目はA4縦。
- 両目は片目平均横幅20/25mm、片目は35/45mm。選んだ素材の実画素の幅から印刷倍率を計算。大きいサイズでは2段にして、目印・空欄を同段の別マスに配置し、眉を含む原形を切らない。
- 各PNG保存、白黒、1枚／2枚の印刷・PDF、50mm校正線、紙を回して描きやすい向きにする案内を維持。
- 画面に描く機能はない。工房で選んだ目を引き継ぐ。
