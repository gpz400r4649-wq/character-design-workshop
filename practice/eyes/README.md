# 目の練習ドリル v149

工房の採用済み6種類の目を使う、独自構成の反復練習シート。既存書籍の紙面・説明・イラストは使用していない。

- 左に見本、右に2つの練習マス。「なぞる」「幅・高さ・中心の目印で描く」「見て描く」の3段階。
- 各マスを大きく開き、指・ペン・マウスで描画。消しゴム、3段階の太さ、取り消し、消去の取り消し、お手本の重ね表示。
- 目の種類・マスごとに線をブラウザー内保存。ローカル保存不可・容量超過時はPNG保存を案内。
- シートは1600×2263 PNG。練習前／描いた線入りを選択。A4縦1ページで印刷・ブラウザーのPDF保存が可能。
- 工房の「練習・保存」から起動。「目のれんしゅう」の旧カードリンクも置き換え、選択中の目を `?style=` で引き継ぐ。髪・服のガイドは継続。

`assets/catalog.js` の `part` は原本の部品ID。PNGは原本からブラウザーCanvasの既存線画方式に沿って抽出した練習用派生素材。原本は変更していない。defaultのみ眼部以外の頬・耳をマスク。線画は見本としての利用を想定し、描く順序の推定や自動採点は行わない。

動作確認: 6種選択、6マス、実描画、重ね表示で線が消えないこと、消去→取り消し、再読込後の線保持、線入り／なしPNG実保存、A4 PDF1ページ、390pxと拡大ダイアログ、工房の選択引継ぎ。ワークスペース `work/practice-drill-v149/` に検証用画像とスクリプト。

この第一弾の使用感を確認後、同じ形式を顔・前髪・服などへ展開できる。
