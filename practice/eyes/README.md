# 目の練習ドリル v150

ユーザーの印刷写真・要望に基づき、画面描画を廃止して印刷・PNGを中心とする反復練習帳へ改訂。

- 工房の6種類の目を元に、まず大きな形を描くための手描き教材パスを作成。原本素材は変更していない。
- 「描く順番」1枚＋「なぞり練習」1枚。順番の一例は上まぶた→下まぶた→黒目の輪→光の丸→ひとみ→まつ毛。
- 順番ページは既に描いた線を灰色、新しく描く線を色・番号・始点の点・方向矢印で示す。
- 練習ページは左の見本と2マスずつの反復。なぞる→幅高さ中心の目印→空欄の3段階。
- 細かな瞳の模様や眉はこの基礎教材には含めず、形を作る線を優先。厳密な唯一の描き順とは案内しない。
- 片目の幅はまつ毛を除き35mmまたは45mm（A4/100%時）。順番ページ・練習ページは同寸法・同縦横比。5cmの校正線付き。
- カラー／完全なグレースケールを切替。白黒時も番号と矢印を維持。
- PNGは各ページごとに保存。印刷・ブラウザーPDFは両方2枚／いずれか1枚を選択。A4縦、内容は8mm以上内側に配置。
- 旧描画dialog、ペン・消しゴム、描画用JS/CSSを削除。過去にユーザーが保存したブラウザーデータは削除しないが参照しない。
- 工房から選択したeyeStyleを引き継ぐ入口は維持。

`stroke-guide.js` は原本と対応する座標で記述した教材用のBezierパス。線を単純化しているため、原本の完成線画そのものとは区別する。`assets/*.png` は元の目を選ぶサムネイルに使用。
