# キャラクター・デザイン工房

髪型・髪の色・目の色・服・服の色を選び、着せ替えと描く練習を楽しめるアプリです。
https://gpz400r4649-wq.github.io/character-design-workshop/

「はじめの色」が元の色です。ブラウン・くろ・ハニー・ピンク・ラベンダーも選べます。
目の色はブルー・グリーン・アンバー・パープル・ローズも選べます。
上着はピンク・ブルー・ミント・レモン・ラベンダーも選べます。白い襟やリボン、スカートの配色は保ちます。
選んだ髪と目、服の色は、プレビュー・完成見本PNG・PSDの各レイヤーに反映します。
目や髪の練習で非表示にした見本レイヤーは、PSDに残しています。線画・シルエット・白紙の表示には色を付けません。
PSDと色付きPNGは利用者のブラウザー内で組み立てます。絵や選択内容をサーバーへ送信する機能はありません。
選択内容は利用者のブラウザー内に記憶します。

入口はindex.htmlです。GitHub Pagesのmain / (root)から配信します。
このリポジトリのキャラクター画像・プログラムは公開されています。
ローカル版・引き継ぎ文書・検証用PSD・アカウント情報は含みません。

お気に入りは3人まで、髪型・服・髪/目/服の色をブラウザーに保存できます。呼び出しても練習モードやガイド設定は変わりません。入れ替えは確認付き、外した子は直後に戻せます。ほかの端末には自動共有されません。
