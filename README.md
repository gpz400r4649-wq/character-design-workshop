# キャラクター・デザイン工房

GitHub Pages向け配信セット。入口はindex.htmlです。
髪型・服・練習・塗り絵を選び、PSDとお手本PNGを保存できます。
PSDは利用者のブラウザー内で組み立てます。サーバーへ絵や選択内容を送信する機能はありません。
選択内容は利用者のブラウザー内に記憶します。
このフォルダの中身だけを専用リポジトリのルートに置き、Pagesのmain / (root)を指定します。
公開すると、この中のキャラクター画像・プログラムは閲覧・取得できる状態になります。
ローカル版・引継ぎ文書・検証用PSD・アカウント情報は含みません。
ローカルのHTMLを直接開く用途には、別に残してあるeyes-kit-v17を使ってください。
iPadのSafariでの表示・ダウンロードの実機確認は、公開後に行います。
