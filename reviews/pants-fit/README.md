# パンツの位置合わせ（確認用）

URL: https://gpz400r4649-wq.github.io/character-design-workshop/reviews/pants-fit/

トップス11種類とショートパンツ・七分丈・くるぶし丈の33組み合わせを個別に調整する。サロペットとシャツワンピースは一体の服のため対象外。

- 画像のドラッグ、左右/上下px、横/縦%。変形原点は2048×3072上の(1036,1290)。
- 体・脚・靴は共通座標のまま、パンツ衣服だけを変形。
- 脚supportはショートパンツ基準。衣服の股から肌が現れないよう、裾より上の隠れる部分をクリップし、変形した裾位置に追従。
- 全身と腰/股拡大、固定ガイド、同じトップスで調整したショートパンツのゴースト表示。
- localStorageで33組の位置と現在選択を保存。別端末への自動同期はない。
- JSON保存/読み込み、全調整値を含む共有リンク、ガイドとゴーストを含めない透過PNG出力。
- JSONはschema/version/source/全数値範囲を検査し、不正なら適用しない。
- 調整値は確認用。本体カタログへは自動反映しない。ユーザー提供のJSON/共有リンクから各トップスのbottomFits/lowerSetsへ登録する。

素材はローカルv84の既存レイヤーから出力（原画80174d4由来）。別PCでもPNG群・catalog.json・HTML/CSS/JSを一緒に配信すれば使用可能。位置合わせは新しく生成した服を使わない。

## v85
ユーザーから受領した33組の調整値を approved-positions.json に保存し、初期値として使用。既存ブラウザの保存値・共有リンクは優先。リセットは今回の採用値に戻す。6トップスの裾周辺だけを調整した素材へ更新。パンツの元画像と変形座標系はv84と同じで二重適用しない。

## v86 固定素体
../body-guide/body-guide.jsを共用し、12基準点と固定素体を表示。服・素体とパンツ・素体だけの3表示と、10〜80%の素体重ね合わせ。衣服のPNG書き出しには確認ガイドを含めない。調整JSONと採用された33組の値は変更しない。
