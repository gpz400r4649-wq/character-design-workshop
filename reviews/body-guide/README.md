# 服合わせ用の固定素体 v86

https://gpz400r4649-wq.github.io/character-design-workshop/reviews/body-guide/index.html?v=86

- 基準キャンバス2048×3072。既存の腕・脚・靴の位置とシルエットを利用。
- 服で見えなかった肩・胴・腰は、胸などの細部のない不透明な練習スーツ形状で補完した簡略図。精密な人体復元ではなく、服合わせの固定基準。
- 腕・脚のマスクは既存素材から4つの大きな連結成分を残し、独立したごみを除く。脚は既存の形を保持し、上端の下地パッチは除外。
- reference-body.svgはPNGをdata URLで内包する単独SVG。ブラウザで表示・PNG保存できる。
- reference.jsonが12点と6本の水平基準線、中心線の唯一の定義。画面左/右表記は見る側。
- body-guide.jsを素体ページと位置合わせツールが共用し、点の二重定義を避ける。
- 素体ページでは素体PNG・基準点つきPNG・線だけPNG・座標JSON・SVGを保存可能。
- パンツ編集では服/素体＋パンツ/素体のみ、素体重ね合わせ10〜80%。素体だけの表示では服の移動を無効化。
- 服を切り替えても基準は固定。服の調整値のJSONは既存schemaを維持。
- 服の全身PNGには素体・ガイドを混入させない。素体の保存は専用ページから。

初期の腰1290/股1669、現在の33組の衣服調整値はそのまま。新しい素体を理由に自動で服を動かさない。今後はこの基準に合わせて服側だけを調整する。
